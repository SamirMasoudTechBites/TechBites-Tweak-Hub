## 🔥 Comprehensive Feature Suite

### 1. 🎮 Smart Game Engine & Automatic Detection
- **Intelligent Drive Scanner**: Deeply scans Steam, Epic Games, Riot, Ubisoft, EA App, Battle.net, and custom install directories to display **only verified, installed games** — zero clutter or irrelevant titles.
- **Engine-Level Competitive Presets**: Precision config injection targeting competitive frametime stability for:
  - *Valorant, Counter-Strike 2 (CS2), PUBG: BATTLEGROUNDS, Fortnite, Call of Duty: Warzone, Apex Legends, Rainbow Six Siege, GTA V / FiveM, Overwatch 2, League of Legends, Dota 2*, and more.
- **DirectX & Vulkan Shader Pipeline**: Optimizes shader pre-caching, disables async compute delays where beneficial, and optimizes CPU draw call thread dispatching.
- **DirectX Graphics Infrastructure (DXGI) Tuning**: Forces native flip model (`DXGI_SWAP_EFFECT_FLIP_DISCARD`), bypasses DWM compositor overhead, and strips forced fullscreen latency.
- **Game DVR & Xbox Capture Stripping**: Eradicates background game clip recording and telemetry processes that steal GPU encoding resources.

---

### 2. ⚡ NVIDIA DRS & Deep Driver Optimization Studio
- **Driver Profile Import & Export**: Directly interfaces with the NVIDIA driver DRS API to import, backup, and restore custom game profiles without requiring third-party tools.
- **Hidden Driver Flag Controls**: Fine-tune deep driver parameters normally invisible in the standard NVIDIA Control Panel:
  - Ultra-Low Latency Mode (Reflex driver-level queuing).
  - Maximum Pre-Rendered Frames configuration.
  - Anisotropic Filtering optimizations and Clamp Negative LOD Bias.
  - Threaded Optimization enforcement.
  - Power Management Mode (*Prefer Maximum Performance* locked at hardware level).
  - Variable Refresh Rate (VRR / G-Sync) frametime alignment.
  - Deep DLSS / DLDSR / Reflex hardware pipeline configurations.

---

### 3. ⏱️ Ultra-Low Latency, DPC & MSI Mode Engine
- **MSI Utility (Message Signaled Interrupts)**: Converts GPU, NVMe controller, USB 3.0/3.1 controllers, and Ethernet/Wi-Fi adapters from legacy line-based Pin-IRQs to high-speed MSI mode.
- **Interrupt Priority Tuning**: Sets GPU and Network Card interrupt priority to *High*, assigning dedicated vector queues for near-instant mouse and network packet delivery.
- **BCD OS Kernel Tweaks**:
  - Sets `useplatformclock` and dynamic tick tuning to eliminate timer jitter.
  - Configures optimal memory page tables for gaming responsiveness.
- **DPC Latency Monitoring & Reduction**: Locates and suppresses driver interrupts causing system-wide latency spikes.

---

### 4. 🔋 Advanced Power Management & CPU Governor
- **TechBites Ultimate Performance Schemes**: Installs custom, unthrottled power plans that expose and unlock hidden Windows ACPI attributes.
- **CPU Core Parking Elimination**: Prevents Windows scheduler from parking CPU performance cores during gaming sessions.
- **CPU Frequency Scaling & Idle State Tuning**: Locks minimum processor frequency state at 100% to eradicate frequency ramp-up latency.
- **USB Selective Suspend & PCI Express Link State**: Disables power-saving downclocking on USB ports (prevents mouse sensor drops) and PCIe slots.

---

### 5. 🧠 Enterprise RAMMap & Memory Optimization
- **Sysinternals-Grade Memory Flusher**: Integrates `RAMMap` and `EmptyStandbyList` execution engines directly into the application.
- **Standby List Instant Purge**: Windows often hoards gigabytes of cached files in the standby list, leading to hitching when memory is requested. TweakHub clears this with 1 click.
- **Working Set & Modified Page Reclamation**: Reclaims unmapped physical pages without crashing or freezing running software.
- **Real-Time Memory Telemetry**: Monitors Committed, Cached, Paged Pool, and Non-Paged Pool memory in real time.

---

### 6. 🚀 Windows Debloater & Privacy Armor
- **UWP & Bloatware Stripper**: Safely uninstalls preinstalled Windows bloatware (Cortana, News & Interests, Feedback Hub, Xbox redundant components, OEM trialware).
- **Comprehensive Telemetry Shield**:
  - Blocks Diagnostic Data (Telemetry) collection and Customer Experience Improvement Program (CEIP).
  - Blocks Microsoft telemetry IP addresses and endpoints at the Windows Firewall and hosts level.
  - Disables Activity History, Tailored Experiences, and Advertising ID tracking.
- **Background Service Optimizer**: Safely disables non-essential background Windows services that eat CPU cycles (Print Spooler, Remote Registry, Diagnostic Execution, SmartScreen telemetry).
- **Scheduled Tasks Cleaner**: Prunes hundreds of hidden telemetry and telemetry consolidation tasks scheduled by Windows Task Scheduler.

---

### 7. 🧹 Deep Disk, Cache & WinSxS Cleaner
- **WinSxS Component Store Pruning**: Cleans superseded updates and accumulated Windows component caches (`DISM /Cleanup-Image`).
- **Delivery Optimization & Windows Update Cache**: Wipes multi-gigabyte leftover Windows Update delivery files and update caches.
- **Browser & Shader Cache Engine**: Cleans Direct3D, OpenGL, Vulkan, and DirectX shader caches along with Chromium browser temporary data.
- **System Junk & Prefetch Scrubber**: Cleans user/system `%TEMP%`, crash dumps, mini-dumps, memory error reports, and log debris.

---

### 8. 🛠️ 1-Click System Repair & Windows Fixes
- **DISM & SFC Integrity Repair**: Automatically executes automated image repair (`DISM /RestoreHealth`) followed by full system file checker verification (`SFC /scannow`).
- **Network Stack & Winsock Reset**: 1-click flushes DNS cache, resets Winsock catalog, and refreshes TCP/IP configurations to solve ping spikes and packet loss.
- **Windows Update Diagnostic Repair**: Re-registers update service DLLs and rebuilds `SoftwareDistribution` catalog to resolve stuck update loops.
- **Print Spooler & Windows Search Rebuilders**: Fixes frozen or crashing background subsystems without rebooting.
